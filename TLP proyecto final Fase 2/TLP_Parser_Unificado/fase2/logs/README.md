# Registros originales y derivados

- `parser.json`: parser LL(1) y arboles obtenidos.
- `spacy.json` y `nltk.json`: anotaciones originales de las herramientas.
- `spacy_cfg.json` y `nltk_cfg.json`: decisiones derivadas de criterios fijos.
- `gemini_zero_shot.jsonl` y `gemini_few_shot.jsonl`: solicitudes, respuestas
  completas y reintentos de Gemini con fecha UTC.
- `llm_zero_shot.json` y `llm_few_shot.json`: decisiones validas para metricas.
