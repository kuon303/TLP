# Resultados reproducibles

`evaluar.py` genera `tabla_metricas.csv`, `tabla_metricas.json`, `errores.csv`
y `grafica_metricas.svg` a partir de los logs binarios.

`evaluar_pos.py` genera `tabla_pos.csv`, `tabla_pos.json` y `errores_pos.csv`
utilizando la referencia POS de 396 tokens.

Los archivos `gemini_zero_shot_respuestas.json` y
`gemini_few_shot_respuestas.json` son vistas compactas de las respuestas.
Los logs originales estan en `fase2/logs/`.
